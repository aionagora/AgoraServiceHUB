PASOS MANUALES (si no usas el script):
  1. Detener API y Web
  2. Matar procesos dotnet en puertos 7001 y 5002:
     > netstat -ano | findstr :7001
     > taskkill /PID {número} /F
  3. dotnet clean
  4. Borrar bin y obj (opcional pero recomendado)
  5. dotnet restore
  6. dotnet build
  7. Iniciar API: cd src\AgoraHub360.ERP.Api; dotnet run
  8. Iniciar Web: cd src\AgoraHub360.ERP.Web; dotnet run

NAVEGADOR:
  1. F12 → Application → Clear Storage → Clear site data
  2. Service Workers → Unregister (si aparece)
  3. Cerrar DevTools
  4. Ctrl+F5 (hard reload)
  5. Login nuevamente
