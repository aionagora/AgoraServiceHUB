  🚨 SI ALGO NO FUNCIONA
═══════════════════════════════════════════════════════════════════════════

  Error                          Solución
  ─────────────────────────────────────────────────────────────────────────
  "Address already in use"    → Ejecuta verificar-puertos.bat
                                 Cierra proceso que usa el puerto

  "Failed to fetch"           → Asegúrate de iniciar API primero
                                 Verifica https://localhost:7001/health

  "CORS policy"               → YA CORREGIDO en la configuración
                                 Si persiste, revisa BlazorBaseUrl

  "Cannot connect to DB"      → Ejecuta 0-test-sqlserver.bat
                                 Verifica que SQL Server esté corriendo

  "Certificate error"         → Acepta el certificado de desarrollo
                                 dotnet dev-certs https --trust
